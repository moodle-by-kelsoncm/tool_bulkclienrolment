Visão Geral - moodle-tool_bulkclienrolment
==========================================

O **moodle-tool_bulkclienrolment** é um plugin de ferramenta administrativa (`admin/tool`) para o Moodle que permite realizar a **matrícula e inscrição em massa de usuários em cursos via linha de comando (CLI)** utilizando arquivos estruturados em formato CSV.

Recursos Principais
-------------------

- **Inscrição em Lote via CLI**: Processamento em segundo plano sem limites de timeout de requisições web.
- **Entrada em CSV Flexível**: Mapeamento direto de nome de usuário, código breve do curso e papel (*role*).
- **Relatório e Diagnóstico**: Exibição detalhada de sucessos e eventuais inconsistências durante o processo.
