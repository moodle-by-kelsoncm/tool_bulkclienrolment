# Visão Geral — moodle-tool_bulkclienrolment

O **`moodle-tool_bulkclienrolment`** é um plugin de ferramenta de administração (`admin/tool`) para o Moodle que permite realizar a **matrícula/inscrição em massa de usuários em cursos via script de linha de comando (CLI)** utilizando arquivos de dados (CSV).

---

## 🚀 Principais Recursos

- **Inscrição em Lote via CLI**: Processamento de grandes volumes de matrículas sem sobrecarregar a interface web.
- **Leitura de Arquivos CSV**: Leitura flexível de arquivos estruturados com identificação de usuários e cursos.
- **Relatório de Execução**: Exibição em tempo real do progresso de matrículas efetuadas e erros encontrados.
