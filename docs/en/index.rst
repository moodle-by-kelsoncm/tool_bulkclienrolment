Overview - moodle-tool_bulkclienrolment
=======================================

**moodle-tool_bulkclienrolment** is an administrative tool plugin (`admin/tool`) for Moodle that enables **bulk enrollment and subscription of users into courses via the command-line interface (CLI)** using structured CSV files.

Key Features
------------

- **Bulk Enrollment via CLI**: Background processing without web request timeout limitations.
- **Flexible CSV Input**: Direct mapping of username, course shortname, and assigned role.
- **Reporting & Diagnostics**: Detailed reporting of successes and potential inconsistencies during execution.
