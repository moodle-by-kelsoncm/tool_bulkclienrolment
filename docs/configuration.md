# Configuração do Arquivo CSV — moodle-tool_bulkclienrolment

## Formato do CSV

O arquivo CSV utilizado pelo script deve conter os identificadores necessários para vincular o usuário ao curso e papel desejado no Moodle.

### Exemplo `simple.csv`:
```csv
username,course_shortname,role
joao.silva,MAT101,student
maria.souza,FIS202,editingteacher
```
